# Geome Explore

Aplikacja mobilna umożliwiająca odkrywanie miast na podstawie doświadczeń innych użytkowników. Pozwala tworzyć i udostępniać tematyczne zbiory miejsc w formie wpisów przypominających playlisty, zawierających osobiste opinie i rekomendacje. Celem aplikacji jest ułatwienie szybkiego znalezienia ciekawych miejsc, również z uwzględnieniem czasu dostępnego na zwiedzanie.

**Przedmiot:** Systemy mobilne, AGH

## Technologie

- Flutter (Dart)
- Supabase (PostgreSQL, Auth)
- Google Places API (planowane)
